# Francisco's CHIM Plugins

My plugins for CHIM and Skyrim. Apparently dragons, civil war, and Nazeem weren't enough.

## Mind Poisoning

The first plugin in this collection. Give Skyrim's gossip an actual consequence: NPCs or the Player can praise or badmouth a named NPC, nudging one listener's opinion. The listener may remain unconvinced—inconvenient for anyone expecting competent character assassination.

**Current candidate:** v0.1.10 is a PRE-ALPHA development-candidate prerelease. Version 0.1.10 skips an otherwise-valid NPC `_speech` acknowledgement when `utterance_id` is absent or an empty/whitespace-only string, reporting info `untracked-speech` / `utterance_id_absent` without inventing a correlation ID or calling the model. Wrong-type or malformed IDs, and other invalid fields, remain warnings. A user-supplied post-release shape-decoding analysis in `critique.md` correlates all 18 observed `invalid-payload` warnings, including the six previously noted, with valid ACK JSON lacking `utterance_id`; this attribution is to that report, not an independent re-decode. Runtime and logging fixtures and touched PHP lint passed for the classification correction. Live CHIM database writes/concurrency, provider behavior, client delivery, deployed dashboard authentication, and in-game behavior have not been verified. Use one installation route per CHIM server; the operator pause remains a sampled control, not an atomic cancellation, and PostgreSQL wait limits bound individual operations rather than total request time.
