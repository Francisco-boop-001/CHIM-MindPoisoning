# Francisco's CHIM Plugins

My plugins for CHIM and Skyrim. Apparently dragons, civil war, and Nazeem weren't enough.

## Mind Poisoning

The first plugin in this collection. Give Skyrim's gossip an actual consequence: NPCs or the Player can praise or badmouth a named NPC, nudging one listener's opinion. The listener may remain unconvinced—inconvenient for anyone expecting competent character assassination.

**Current candidate:** v0.1.9 is a PRE-ALPHA development-candidate prerelease. Source and fixture checks passed, including a disposable PostgreSQL 15 test of transaction-local wait bounds. Live CHIM database writes/concurrency, provider behavior, client delivery, deployed dashboard authentication, and in-game behavior have not been verified. The official CHIM catalog entry has not been submitted or approved.

Version 0.1.9 adds fixed, content-free reason codes for new malformed NPC `_speech` acknowledgements while preserving their skipped `invalid-payload`/`oversized` statuses; earlier aggregate rejections cannot be diagnosed retroactively. An operator-managed `data/mind_poisoning.json` file can pause new model work and block persistence if observed after the model call. This is a sampled control, not an atomic cancellation. PostgreSQL transaction-local `lock_timeout` (1,000 ms) and `statement_timeout` (3,000 ms) bound individual waits, not the total request; failures are not classified by parsing database error text. These changes retain the v0.1.8 shared-server behavior when no CHIM profile is active and the v0.1.7 Player-origin path, which is separate from NPC `_speech` acknowledgements and does not prove audio delivery. Live database writes/concurrency, provider behavior, client event delivery, deployed dashboard authentication, and in-game behavior remain unverified.
