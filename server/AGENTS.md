# Contributor notes

- Keep the plugin within the package allowlist and compatible with HerikaServer reference `cf5030f15781637498be86debe26fcf102f5690d`. Do not add core edits, credentials, config, migrations, dependencies, daemons, or install scripts.
- Handle only an exact client `_speech` acknowledgement matched to the emitted event and active playthrough. Require one NPC speaker/listener; skip Player listeners, uncertain identities, more than 8 subjects, or speech over 12,000 bytes.
- Skip when the global relationship feature is disabled, CHIM interaction is Off, or `NEVER_CLEAR_RELATIONSHIP_DATA` is true. Also skip listeners with nonzero `lock_profile` or a manual relationship lock; `relationships_locked` uses PHP `!empty` semantics.
- Use only the configured `openrouterjson` or `openrouterjsoncached` connector. Do not select another connector or add retries. Preserve connector globals, use the existing I/O timeout of 12 seconds and 1024-token limit, and do not claim a hard wall-clock cap.
- Apply only model-validated integer deltas from -5 through +5, including zero; clamp affinity to -100 through +100. Preserve relation types and unrelated plugin/core fields. Never write native Skyrim relationship ranks or turn hearsay into shared world knowledge.
- Keep the synchronous model call outside transaction locks. For persistence, use the guarded `sql::$link` compatibility shim, retain one native connection, take the listener advisory lock and row lock, then commit the affinity, exact-event ledger, and full NPC/history snapshot together. Zero decisions still need a ledger entry and snapshot. Fail closed on transaction, write, or snapshot failure.
- Bound dedupe to 128 IDs and maintain the numeric eviction floor. Skip ACKs at or below the floor, including unseen out-of-order IDs. Core restore with `NEVER_CLEAR_RELATIONSHIP_DATA=true` rewinds plugin ledger state, so the hook must stay disabled under that policy.
- Removing the plugin stops future evaluations; it does not undo stored affinity. Some upstream writers ignore the shared advisory lock and may overwrite a later plugin update. Fixture checks are not live PostgreSQL, provider, or in-game proof.
- Local source, fixture, and read-only SQL planning checks are lead-reviewed for this development candidate. Upload only to an isolated test instance; live runtime and in-game acceptance remain pending.
