## Changes

- `server/dashboard.php`: unauthenticated loopback requests now require an HTTP `Host` of `localhost`, a valid IPv4 address in `127.0.0.0/8`, or bracketed IPv6 `::1`; an optional port must be 1–65535. A missing, malformed, non-local Host or any forwarded-address header denies loopback access before dashboard data is loaded. Server-authenticated remote requests retain their existing access path. The explicit non-loopback `local=1` handoff still redirects to the fixed localhost URL, including when its request Host is hostile; the handoff marker cannot turn a loopback Host failure into authorization.
- `server/dashboard_data.php`: dashboard search now walks nested array/object field values, searches string values as written, and never matches field names. This makes quote and backslash searches work while preserving scalar text matching. Log tail reads inspect the byte before the bounded offset and discard the first tail line only when the offset cuts through a record. Public reader signatures and return shapes are unchanged.
- `tests/dashboard_integration_test.php`: incorporated the review-branch fixture correction that copies `restore_policy.php`, and made the “Current affinity unavailable” markup assertion tolerate rendered whitespace.
