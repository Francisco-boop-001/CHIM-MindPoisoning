# Mind Poisoning v0.1.19 — PRE-ALPHA

This is a packaging-only update to the PRE-ALPHA release. Runtime behavior, APIs, and algorithms carry forward unchanged from v0.1.18.

## MO2 package

The recommended plain MO2 ZIP adds a root `meta.ini` with version `0.1.19` and the repository source URL. It contains the version-matched DWPkg at `CHIM/server-plugins/mind_poisoning/0.1.19.dwpkg`; MO2 users need only this ZIP. The metadata does not represent CHIM installation state, and this release adds no `validated` flag or fake Skyrim game files.

MO2 may still show its Skyrim game-content warning because the payload contains CHIM server data rather than recognized game files. That warning does not establish whether CHIM can read or synchronize the package.

The raw DWPkg is an advanced alternative for manual CHIM file sync. The server TAR is an advanced alternative for an existing explicit manifest/channel install. Use one route per CHIM server. `SHA256SUMS.txt` verifies downloaded bytes; it does not install the plugin. GitHub's autogenerated Source code archives are not installers.

## Verify installation

Launch Skyrim through MO2 with CHIM connected and load a save. On CHIM's Server Plugins page, open **Automatic Game Plugin Sync** and choose **Refresh Status**. Confirm `mind_poisoning` version `0.1.19` is installed before opening CHIM Plugin Manager → **Plugin Page**. A ZIP download, root `meta.ini`, checksum, or MO2 **Ignore/Continue** choice does not prove CHIM read or synchronized the package.

## Known report limit

A community report described a CHIM “couldn't read” error but supplied no exact error text, filename, logs, or client/server revisions. Its cause and relation to this package remain unknown; v0.1.19 does not claim to fix it. No native MO2 warning-removal or installed CHIM sync result is claimed.
