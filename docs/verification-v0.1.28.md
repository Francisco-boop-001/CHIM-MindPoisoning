## Changes covered by focused checks

- Recognized child signals suppress only intimacy-arrangement classification and exposure. Ordinary child-target affinity and emotional-type judgments remain available; a complete prior blocked arrangement record remains unchanged. Eligible adult sibling arrangements still persist. The guard mirrors known SHARMAT signals and is not universal age verification.
- Arrangement context stops when recognition is off or MP is paused. Same-kind reaffirmation preserves its receipt and provenance but counts as zero semantic arrangement changes.
- Optional child metadata uses a bounded, read-only native query. The production reflection fixture verifies that an ineligible late arrangement is suppressed while ordinary and eligible sibling judgments are retained.
- Written source identity checks use bounded keyset pages, preserve exact valid document/receipt/operation conflicts, and ignore malformed unrelated marked rows. A cooperative three-second deadline is checked between synchronous reads; an expired or incomplete scan fails closed. It cannot interrupt a query already in flight.
- The actual MAIN restore barrier uses its helper's three-second wait setting. Polling granularity means this is not a hard cap on total request time. The serialization remains per CHIM host; it is not distributed across hosts.
- Fixed written-evidence preflight diagnostics report that model and persistence were not attempted. Dashboard tests keep these stop records in diagnostics, not applied-interaction cards. The diagnostics-cap fixture derives its boundary from the active cap.

## Limits and compatibility

The written-evidence API was introduced in 0.1.27 and is optional. It requires a compatible server-side producer, which is not supplied by this package. A development producer used in an integration fixture is not a public Correspondence release. A confirmed exposure does not prove authorship, payment, message delivery or reading, or create an intimacy arrangement.

Intimacy recognition remains off by default. An NPC's report is not mutual agreement, exclusivity or current willingness. The recognized-child guard covers the known name, flag and race signals only; missing or modded metadata can evade it. An optional child-metadata SQL error inside an owned PostgreSQL transaction can abort the atomic batch, so an ordinary reflection update is not guaranteed to survive every metadata failure. A mid-request recognition-setting change can also cancel the reflection write. SHARMAT's native actor check remains authoritative for its action path. Mind Poisoning does not update SHARMAT, guarantee action eligibility or prove OStim playback.
