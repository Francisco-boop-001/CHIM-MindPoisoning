# Mind Poisoning 0.1.29 — BETA CANDIDATE

## A small punctuation repair

NPC names with apostrophes now stay readable when included in private arrangement prompt context. Markup, ampersands, double quotes and control characters remain JSON-escaped. No relationship records or policy decisions change; apparently even the llama prefers J'zargo without extra backslashes.

Intimacy recognition remains optional and off by default. This release does not tighten or broaden its child-signal checks: recognized child signals suppress only arrangement classification or exposure, while ordinary affinity, emotional type, gossip and reflection remain available. This is not universal age verification, and missing optional child metadata is not evidence of adulthood. One NPC's report still does not establish the other person's agreement, exclusivity or current willingness.

The written-evidence API is unchanged from 0.1.28 and still requires a compatible server-side producer, which is not included. The retained synthetic scan measurement is unchanged; 0.1.29 is not a scan-performance fix.

After the release assets are published, verify `SHA256SUMS.txt`. A checksum verifies downloaded bytes, not CHIM synchronization. Choose exactly one route per server:

- **MO2 users:** [plain MO2 ZIP](https://github.com/Francisco-boop-001/CHIM-MindPoisoning/releases/download/mind_poisoning-v0.1.29/mind_poisoning-0.1.29-mo2.zip). It includes the version-matched DWPkg; update with **Replace**, not **Merge**.

- **Advanced manual sync:** [versioned DWPkg](https://github.com/Francisco-boop-001/CHIM-MindPoisoning/releases/download/mind_poisoning-v0.1.29/mind_poisoning-0.1.29.dwpkg).
